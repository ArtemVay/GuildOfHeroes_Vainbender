### Новые методы из 2 практической
1. Получения урона (недопустимый урон это тот который отрицательный, то есть меньше 0)
2. Получение лечения
3. Получения опыта
4. Проверка жив ли персонаж
5. Вывод информации о персонаже

### Итоговые характеристики персонажей после 2 практической
```
>>> Ярослав <<<
Здоровье: 85
Уровень: 1
Опыт: 65

>>> Анастасия <<<
Здоровье: 60
Уровень: 1
Опыт: 0

>>> Артём <<<
Здоровье: 0
Уровень: 1
Опыт: 0
```

## Собственный проект

### Тема проекта: *Персонажи*

### Главный класс: *Character*

### Почему этот объект нужен программе:
Без него придётся прописывать переменные по одному и тому же шаблону очень много раз, а как можно использовать готовый класс сделав код читабельный и более простым в написание

### Какие данные хранит объект:
- Имя: `Name`
- Возраст: `Age`
- Раса: `Race`
- Происхождение: `Origin`
- Статус (жив или мёртв): `IsAlive`

### Какие значения задаются через конструктор:
1. Имя
2. Возраст
3. Раса
4. Происхождение

### Какие значения можно задавать автоматически:
Только статус

## Дополнительное задание
Я решил создавать автоматически поле `IsAlive` потому что в большинстве случаев он будет жив. Наврядли будут добавлять умерших персонажей
