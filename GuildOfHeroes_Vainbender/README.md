## Собственный проект

### Тема проекта: *Персонажи*

### Главный класс: *Character*

### Почему этот объект нужен программе:
Без него придётся прописывать переменные по одному и тому же шаблону очень много раз, а как можно использовать готовый класс сделав код читабельный и более простым в написание

### Какие данные хранит объект:
- Имя: `Name`
- Возраст: `Age`
- Раса: `Race`
- Происхождение: `Origin`
- Статус (жив или мёртв): `IsAlive`

### Какие значения задаются через конструктор:
1. Имя
2. Возраст
3. Раса
4. Происхождение

### Какие значения можно задавать автоматически:
Только статус

## Практическая 2

### Поведение главного класса

### Метод 1: `Grow(int n)`
Что делает: увеличивает возраст персонажа на `n` лет, если персонаж жив и `n > 0`. Если персонаж мёртв или передано неположительное значение, возраст не меняется.

### Метод 2: `Rename(string rn)`
Что делает: меняет имя персонажа на переданную строку `rn`.

### Метод 3: `GetInfo()`
Что возвращает: строку с информацией о персонаже — имя, возраст, раса, происхождение и статус (`Жив`/`Мёртв`). Результат зависит от текущего состояния объекта.

Возраст, имя и статус — собственные характеристики персонажа, поэтому правила их изменения и вывода информации должны храниться внутри `Character`, а не повторяться во внешнем коде.

## Дополнительные вопросы по своему коду

1. Поле хранит данные объекта (`public int Age;`), метод экземпляра описывает действие объекта (`public void Grow(int n)`). Поле - состояние, метод — поведение.
2. Аргумент из скобок при вызове попадает в параметр в заголовке метода. Пример: `arin.Grow(5);` - здесь `5` попадает в параметр `n`.
3. `void` - метод ничего не возвращает. Пример: `public void Grow(int n)` и `public void Rename(string rn)`.
4. `return;` просто завершает метод и ничего не возвращает. `return Health > 0;` завершает метод и возвращает `true` или `false`. В моём `Grow` используется `return;` в `else`, а возврат значения - в `Hero.IsAlive()`.
5. `bool` возвращает `true` или `false`. Сохранить можно так: `bool yaroslavAlive = yaroslav.IsAlive();`. В моём `Character` поле `IsAlive` тоже имеет тип `bool`.
6. `GetInfo()` только формирует текст через `return`, а печать делает `Program.cs`: `Console.WriteLine(arin.GetInfo());`. Класс не зависит от консоли.
7. Метод экземпляра работает с полями получателя вызова. `arin.Grow(5);` меняет `Age` у `arin`, `lira.Grow(2);` - у `lira`, и они не влияют друг на друга.
8. Поля объявлены `public`, поэтому их можно менять напрямую в обход методов: `arin.Age = -500;` или `arin.IsAlive = false;`. Защита будет в следующей работе.
